# 登录接口测试用例

| 编号 | 测试场景 | 输入 | 预期结果 |
|---|---|---|---|
| 1 | 正确用户名和密码 | admin / 123456 | 200，返回 Token |
| 2 | 密码错误 | admin / wrong | 401 |
| 3 | 用户名为空 | 空 / 123456 | 400 |
| 4 | 密码为空 | admin / 空 | 400 |
| 5 | 用户不存在 | nobody / 123456 | 401 或 404 |
| 6 | 缺少用户名参数 | 只传 password | 400 |
| 7 | 缺少密码参数 | 只传 username | 400 |
| 8 | 错误的 Content-Type | text/plain | 400 或 415 |
| 9 | 超长用户名 | 超长字符串 | 400，不崩溃 |
| 10 | 连续多次登录 | 相同账号重复登录 | 返回结果符合接口设计 |
